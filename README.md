Public backend service that creates short URL keys and redirects users to their original URLs.

- URL validation and scheme normalization
- Health-check endpoint and environment-based configuration
- API testing and deployment-oriented service design
- [View the repository](https://github.com/Arbinchaudhary240/django-high-throughput-url-shortener)
- Technologies: Python, Django, PostgreSQL, RESTful architecture

### Task Management Platform

Public multi-user task management application with CRUD operations, filtering, and status updates.

- Django validation and session-based access handling
- Timezone-aware datetime handling for Nepal Standard Time (UTC+5:45)
- [View the repository](https://github.com/Arbinchaudhary240/Task_manager_app)
